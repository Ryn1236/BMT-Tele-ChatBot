# OneBMT – Telegram Chatbot

A Python-based Telegram chatbot developed to provide parents with quick access to Basic Military Training (BMT) information, frequently asked questions, and relevant contact information.

The project aims to improve information accessibility and reduce repetitive manual enquiries through automated responses.

## Features

- **Automated Responses:** Provides answers to frequently asked questions.
- **Information Accessibility:** Allows parents to retrieve relevant BMT information directly through Telegram.
- **24/7 Availability:** Hosted on a Raspberry Pi 4 to keep the chatbot running continuously.
- **Automatic Startup:** Configured to launch the chatbot automatically after system restarts or power interruptions.

## Technologies Used

- **Language:** Python
- **Platform:** Telegram Bot API
- **Library:** python-telegram-bot
- **Hardware:** Raspberry Pi 4
- **Operating System:** Raspberry Pi OS
- **Remote Access:** SSH

## Deployment

The chatbot was deployed on a Raspberry Pi 4 in a headless configuration, allowing remote administration through SSH without requiring a monitor or keyboard.

Automatic startup was configured to ensure the chatbot launches whenever the Raspberry Pi boots, allowing it to operate continuously with minimal manual intervention.

## Project Context

Originally developed to support communication and information accessibility for parents during Basic Military Training (BMT).
